# Eval case: login-feature

Tarea para el pipeline SDD: implementar autenticación de usuario (login con email/contraseña y
expiración de sesión). El candidato debe producir un change OpenSpec coherente, con el requisito
"User Login" especificado, código trazado a `@conductor REQ-LOGIN` y tests.

Se puntúa con `rubric.json` (gate + trazabilidad + presencia del requisito).
